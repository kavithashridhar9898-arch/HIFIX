###  Bringing Trusted Home Services to Your Fingertips

HiFix is a premium AI-powered mobile application that connects homeowners with verified local professionals for a wide range of home services. Whether it's an emergency repair or routine maintenance, HiFix enables users to discover skilled workers nearby, book services in real time, communicate seamlessly, and manage appointments through an intuitive mobile experience.

Built using **React Native**, **Node.js**, **Express.js**, and **MySQL**, HiFix combines intelligent worker recommendations, secure authentication, real-time messaging, GPS integration, and a scalable backend to deliver a modern, reliable, and user-friendly home service platform.

</div>

---

##  Why HiFix?

Finding trustworthy professionals for home maintenance can be time-consuming and uncertain. HiFix simplifies this process through AI-driven recommendations, real-time communication, and location-aware service discovery, ensuring users can quickly connect with the right expert whenever they need assistance.

Whether you're looking for an electrician, plumber, carpenter, painter, AC technician, mechanic, or gardener, HiFix provides a secure and seamless booking experience from start to finish.

To become the most trusted intelligent home service marketplace by leveraging Artificial Intelligence, location technology, and secure digital infrastructure to redefine how homeowners discover and hire skilled professionals.

# 📱 Frontend Architecture

The frontend is developed using **React Native with Expo**, following a component-based architecture that emphasizes code reusability, modularity, and maintainability.

| Directory | Purpose |
|-----------|---------|
| `assets/` | Images, icons, splash screen, fonts, illustrations |
| `components/` | Reusable UI components |
| `screens/` | Individual application screens |
| `navigation/` | Stack and tab navigation configuration |
| `context/` | Global state management |
| `hooks/` | Custom React hooks |
| `services/` | API communication |
| `utils/` | Utility/helper functions |
| `constants/` | Colors, themes, configuration values |

---

# ⚙️ Backend Architecture

The backend follows a layered Express.js architecture that separates business logic from routing and database operations.

| Directory | Purpose |
|-----------|---------|
| `controllers/` | Handles request processing and business logic |
| `routes/` | Defines REST API endpoints |
| `middleware/` | Authentication and request validation |
| `models/` | Database interaction layer |
| `config/` | Environment and configuration files |
| `database/` | Database connection and queries |
| `utils/` | Shared helper functions |
| `uploads/` | User-uploaded images and documents |

# ⚙️ Backend Setup

Open a new terminal.

```bash
cd backend
```

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

or

```bash
node server.js
```

If everything is configured correctly, the backend should start successfully and listen on the configured port.

---

# 🗄️ Database Setup

Create a MySQL database.

```sql
CREATE DATABASE hifix;
```

Import your schema.

```bash
mysql -u root -p hifix < schema.sql
```

Update the database configuration inside your backend.

Example:

```env
DB_HOST=localhost
DB_PORT=3306
DB_NAME=hifix
DB_USER=root
DB_PASSWORD=your_password
```

Restart the backend after saving the configuration.

# 👤 Users Table

Stores information about registered customers.

| Field | Type | Description |
|-------|------|-------------|
| id | INT | Primary Key |

| email | VARCHAR | Email Address |
| phone | VARCHAR | Contact Number |
| password | VARCHAR | Hashed Password |
| address | TEXT | User Address |
| profile_image | VARCHAR | Profile Picture |
| created_at | TIMESTAMP | Registration Date |

---

# 👷 Workers Table

Stores details about service professionals.

| Field | Type | Description |
|-------|------|-------------|
| id | INT | Primary Key |
| name | VARCHAR | Worker Name |
| profession | VARCHAR | Electrician, Plumber, etc. |
| experience | INT | Years of Experience |
| rating | DECIMAL | Average Rating |
| phone | VARCHAR | Contact Number |
| email | VARCHAR | Email |
| availability | BOOLEAN | Available or Busy |
| location | VARCHAR | Current Service Area |

---

# 📅 Bookings Table

Tracks service bookings.

| Field | Type | Description |
|-------|------|-------------|
| id | INT | Primary Key |
| user_id | INT | References Users |
| worker_id | INT | References Workers |
| service_type | VARCHAR | Requested Service |
| booking_date | DATETIME | Scheduled Date |
| booking_status | VARCHAR | Pending, Accepted, Completed |
| payment_status | VARCHAR | Paid or Pending |

---

Stores communication between users and workers.

| Field | Type |
|-------|------|

# 🚀 Deployment Guide

This guide explains how to deploy the HiFix mobile application and backend for production.

# 📦 Deployment Overview

HiFix consists of three primary components:

| Component | Technology | Deployment |
|-----------|------------|------------|
| 📱 Mobile App | React Native (Expo) | Android APK / AAB / iOS IPA |
| ⚙️ Backend API | Node.js + Express | Render / Railway / VPS / AWS |

# 📂 Backend Environment Variables

Create a production `.env` file.

```env
NODE_ENV=production

PORT=5000

DB_HOST=your_database_host

DB_PORT=3306

DB_NAME=hifix

DB_USER=your_database_user

DB_PASSWORD=your_database_password

JWT_SECRET=your_production_secret
```

Never commit this file to GitHub.

# ❓ Frequently Asked Questions (FAQ)

## What is HiFix?

HiFix is a mobile platform that connects homeowners with nearby verified service professionals such as electricians, plumbers, carpenters, painters, gardeners, and more.

---

## Which technologies are used?

- React Native (Expo)
- Node.js
- Express.js
- MySQL
- JWT Authentication

---

## Is HiFix open source?

Yes. Community contributions are welcome through GitHub.

---

## Which platforms are supported?

- Android ✅
- iOS (planned) 🚧

---

## Is an internet connection required?

Yes. HiFix communicates with its backend API for authentication, bookings, chat, and service management.

---

## How can I run the project locally?

Follow the **Installation & Setup** section earlier in this README.

---

## Is payment supported?

The architecture is designed to support online payments. Payment gateway integration is planned for a future release.

---

## Can workers register themselves?

Yes. Workers can create accounts, manage profiles, and receive booking requests.

---

## How do I report a bug?

Open an issue in the GitHub repository with detailed reproduction steps, logs, and screenshots if available.

---

## How can I contribute?

See the **Contributing** section above for guidelines on submitting issues, features, and pull requests.
